# Transport behavior matrix

A transport is an opaque carrier; it does not establish message delivery, authorization, or authoritative state. Rows separate component evidence from a live product path.

| Transport/path | Implemented surface | Runtime evidence | Status / limitation |

Receiver sync reported `accepted 1, pending 0, duplicates 0, checkpoint-excluded 1`; the fresh event projected, the older checkpoint-covered ciphertext did not, and sender history contained the reverse-direction event. Exact run and event IDs are in [`INTEROP_MATRIX.md`](INTEROP_MATRIX.md). | VERIFIED for the recorded checkpoint-aware Desktop↔Desktop path and the one-round Desktop↔CLI event path; full convergence, removal/rekey, courier delivery and Android/Web interop remain unverified. |
